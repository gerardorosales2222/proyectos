Desarrollo.

1. Sus pilares fundamentales son:
   TRANSPARENCIA: Visualizar todos los procesos a todos los miembros del egupo.
   INSPECCIÓN: Monitoreo constante de los progresos para detectar disvíaciones  a tiempo.
   ADAPTACIÓN: Ajustes rapidos ante cambios para  mantener el rumbo hacia el objetivo objetivo.

2. Su mayor ventaja

Es la visibilidad y flexibilidad tatal para todos los miembros de equipo y la poca posibilidad de errores por la alta revisión mediante los sprint.

3. Tiene en total 5 fases fundamentales

- Sprint Planning: Se decide que tareas se van a hacer y los encargados de Cada una.
- Daily Sprum: 15 min de reunion todos los dias para ver  como van el proceso de tareas.
- Refinamiento: revisión del producto para estimular si se solicita más tiempo y requerimientos.
- Revisión del Spring: Equipo y el Cliente se reunen a mostrar todos los procesos completo
- Restrospectiva: El equipo entero análiza como salío el Spring para mejorar los errores.


4. Scrum es mas eficiente cuando el trabajo es complejo, cambiante y requiere feedback constante.

5. Las Daily Scrum sirven para poder evitar errores y llevar control de como van evolucionando los procesos.

Las preguntas fundamentales Son:

- ¿Qué hice ayer?
- ¿Qué voy a hacer hoy?
- ¿Qué obstaculos tube?
